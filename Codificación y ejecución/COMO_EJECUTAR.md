# Ejecución y pruebas

Abre una terminal en la carpeta que contiene `main.py`.

El menú principal permite acceder a:

1. Gestión de usuarios.
2. Gestión de recursos (libros, equipos y salas).
3. Inventario por sede y recurso.
4. Préstamos, devoluciones e historial.
5. Turnos y fila de espera.
6. Categorías.
7. Informes de uso e inventario.
8. Demostración de estructuras de datos.
9. Demostraciones de funciones inteligentes.

Selecciona `0` para salir o volver desde los submenús.

## Ejecutar las pruebas

```bash
python pruebas/test_basico.py
python pruebas/test_correcciones_menu.py
```

La primera prueba estructuras de datos, herencia y gestores básicos. La segunda
comprueba correcciones de préstamos, devoluciones, turnos, inventario, categorías
e informes.
